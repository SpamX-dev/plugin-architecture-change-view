# Назначение

Задавать локальные контракты ответственности каталогов через module.md и
предоставлять агентам правила их ведения и инструменты чтения этих границ.

# Границы

Модуль владеет MCP-сервером, каноническим скиллом module-boundaries и проверкой
наличия описаний во всех каталогах дерева исходного кода. Запись описаний
выполняет агент своими файловыми инструментами.

Экспорт скиллов в Codex принадлежит отдельному адаптеру. Извлечение символов,
разрешение зависимостей и индексация AST принадлежат ast-index. Эвристические
оценки не заменяют принятый контракт ответственности.

# Ограничения

Инструменты сервера читают только настроенный корень проекта. Содержимое
module.md описывает устойчивую ответственность и границы; история изменений
и статусы реализации хранятся отдельно.
