# Назначение

Обслуживать MCP-протокол, выдавать канонический скилл и читать локальные
контракты ответственности в дереве исходного кода.

# Границы

Каталог содержит запуск сервера, каталог инструментов и обход исходных файлов.
Он определяет покрытие описаниями, но не выводит ответственность из имён
каталогов, не оценивает архитектуру и не изменяет пользовательские файлы.

# Ограничения

Пути разрешаются внутри настроенного корня. Ссылки на внешние каталоги,
зависимости и результаты сборки не расширяют область анализа. Неполный обход
должен сообщать об ограничении результата.
