# Назначение

Проверять наблюдаемый контракт MCP и корректность покрытия дерева исходников
локальными описаниями ответственности.

# Границы

Тесты используют временные проекты и реальные stdio-соединения. Они проверяют
границы файловой области, ignore-правила и явное представление неполноты.
Смысл пользовательской ответственности не определяется тестовыми эвристиками.
